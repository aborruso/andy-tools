# Future ideas

## 2026-05-14

### md-gist follow-ups inspired by gisthost.github.io

Source:
- https://simonwillison.net/2026/Jan/1/gisthost/

Ideas to evaluate later:
- Add an option to return a `gisthost.github.io` URL for HTML gists, not just the gist page URL.
- Consider a sibling tool or mode for publishing quick HTML artifacts to Gist and returning a browser-renderable share URL.
- Support larger-file follow-up flows by resolving URLs through the Gist API instead of assuming inline JSON content is always enough.
- Add output modes for different sharing targets, for example: gist page, raw URL, or rendered-host URL.
- Explore whether `md-gist` should eventually emit a share bundle: page URL, raw URL, and rendered URL when applicable.
- Keep in mind the usefulness of gist-hosted lightweight publishing for agent-generated artifacts, notes, and exported reports.
